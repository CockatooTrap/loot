# LOOT

### Load order optimization tool for Bethesda games

LOOT (Load Order Optimisation Tool) automatically sorts the load order of plugins for Skyrim, Fallout, and other Bethesda games, preventing crashes and ensuring maximum compatibility between mods.

<br>

---

## Features

| | |
|:---|:---|
| **Automatic Sorting** | Analyzes your mod list and produces an optimized load order instantly |
| **Error Checking** | Detects conflicts, missing masters, and dirty plugins with detailed warnings |
| **Masterlist Database** | Community-maintained metadata for thousands of individual mods |
| **Multi-Game** | Supports all major Bethesda games from Morrowind to Starfield |
